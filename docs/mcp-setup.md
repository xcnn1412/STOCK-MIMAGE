# เชื่อม Claude เข้ากับระบบ STOCK-MIMAGE (คู่มือผู้ใช้)

ให้ Claude บน claude.ai หรือ Claude Desktop อ่านข้อมูลสต็อก อีเวนต์ และติดตามงานของเราได้ โดยเห็นเฉพาะส่วนที่บัญชีของคุณมีสิทธิ์ และ**อ่านได้อย่างเดียว** แก้อะไรไม่ได้

## ขั้นตอนเพิ่มการเชื่อมต่อ (ทำครั้งเดียว)

1. เปิด [claude.ai](https://claude.ai) → **Settings** → **Connectors** → **Add custom connector**
2. กรอก
   - **Name:** `STOCK-MIMAGE`
   - **Remote MCP server URL:** `https://<โดเมนของระบบ>/api/mcp` (เช่น `https://stock.mimage.co/api/mcp` — ถามแอดมินถ้าไม่แน่ใจ)
   - ช่อง OAuth Client ID / Secret ใน Advanced **ไม่ต้องกรอก**
3. กด **Add** แล้วกด **Connect** — จะมีหน้าต่างใหม่เปิดมาที่ระบบของเรา
4. ล็อกอินด้วย**เบอร์โทรและ PIN เดิม** (ถ้ายังไม่ได้ล็อกอินอยู่)
5. หน้า "อนุญาตให้ Claude เข้าถึง" จะบอกว่า Claude จะเห็นโมดูลไหนบ้าง → กด **อนุญาต**
6. กลับมาที่ claude.ai จะเห็นสถานะ Connected — เริ่มถามได้เลย

**Claude Desktop** ใช้บัญชี claude.ai เดียวกัน: เมื่อเพิ่มใน claude.ai แล้ว เปิด Claude Desktop → Settings → Connectors จะเห็น STOCK-MIMAGE อยู่แล้ว (ถ้าไม่เห็น ให้เพิ่มจากในแอปด้วยขั้นตอนเดียวกัน)

**มือถือ:** แอป Claude ใช้การเชื่อมต่อเดียวกับ claude.ai

## Claude จะเห็นอะไรบ้าง

ขึ้นกับสิทธิ์โมดูลในบัญชีของคุณ (แอดมินเห็นครบ)

| โมดูล | สิ่งที่ถามได้ |
|---|---|
| สต็อก | สรุปสต็อก · ค้นหาอุปกรณ์ (ชื่อ, serial, หมวด, สถานะ) · วัสดุสิ้นเปลืองใกล้หมด · สถานะกระเป๋าแต่ละใบ (ออกงาน / จองไว้ / ในคลัง, นำออกครบหรือยัง, ขาดชิ้นไหน) · ของบนชั้นตามรหัสชั้นและผลตรวจนับล่าสุด |
| อีเวนต์ | งานที่กำลังจะถึง (วัน เวลา สถานที่ กระเป๋าที่จอง ทีมงาน) · รายละเอียดงานหนึ่งงาน · ประวัติปิดงานในช่วงวันที่ (ของเสีย/หาย, วัสดุสิ้นเปลืองที่ใช้) |
| ติดตามงาน | งานที่ยังไม่พร้อมและสิ่งที่ยังขาด (ออกแบบ จัดคน จัดรถ เวลาเริ่ม กระเป๋า) |

Claude **ไม่เห็น** การเงิน ใบเบิก เงินเดือน ข้อมูลลูกค้าใน CRM เอกสาร และรหัสผ่านใดๆ

## ตัวอย่างคำถาม

- "ของอะไรใกล้หมดบ้าง เหลือเท่าไร อยู่ชั้นไหน"
- "กระเป๋า Selfie 6 อยู่ไหน ออกงานอยู่หรือเปล่า ขาดชิ้นไหน"
- "งานสัปดาห์หน้ามีอะไรบ้าง กระเป๋าจัดครบหรือยัง"
- "เดือนที่แล้วปิดงานแล้วมีของเสียหรือหายกี่ชิ้น ชิ้นไหนบ้าง"
- "งานไหนยังไม่พร้อม ขาดอะไร"
- "ชั้น A-01-2 มีอะไรอยู่บ้าง ตรวจนับล่าสุดเมื่อไร"

## ยกเลิกการเชื่อมต่อ

- ในระบบ: เมนูล่างซ้าย **แอปที่เชื่อมต่อ** (`/connected-apps`) → กด **ยกเลิก** ที่รายการนั้น — Claude จะใช้ข้อมูลไม่ได้ทันที
- ใน claude.ai: Settings → Connectors → Remove (แนะนำให้ยกเลิกในระบบด้วย)
- แอดมินเห็นการเชื่อมต่อของทุกคนและยกเลิกแทนได้ที่หน้าเดียวกัน

## เรื่องความปลอดภัยที่ควรรู้

- การเชื่อมต่ออายุ 30 วัน ต่ออายุเองเมื่อมีการใช้งาน ไม่ต้องทำซ้ำถ้าใช้สม่ำเสมอ
- ล็อกอินเว็บจากเครื่องอื่น**ไม่ตัด** การเชื่อมต่อของ Claude แต่ถ้าบัญชีถูกระงับหรือยกเลิกอนุมัติ Claude จะหยุดเห็นข้อมูลทันที
- ทุกครั้งที่ Claude ดึงข้อมูล ระบบบันทึกว่าใคร เมื่อไร ดึงอะไร (ดูได้ในหน้า Logs สำหรับแอดมิน) — ไม่บันทึกข้อความแชต
- ข้อมูลที่ Claude ดึงไปจะอยู่ในประวัติแชตของ claude.ai ของคุณ อย่าแชร์แชตนั้นให้คนนอก

## ติดปัญหา

| อาการ | สาเหตุ / ทางแก้ |
|---|---|
| หน้าอนุญาตบอก "ไม่มีโมดูลที่ Claude ใช้ได้" | บัญชีไม่มีสิทธิ์ สต็อก / อีเวนต์ / ติดตามงาน — ให้แอดมินเปิดสิทธิ์ที่หน้า Users |
| หน้าอนุญาตบอก "เชื่อมต่อไม่ได้ … ไม่รู้จักแอปนี้" | ลบ connector ใน claude.ai แล้วเพิ่มใหม่ |
| Claude บอกว่าเรียกถี่เกินไป | จำกัด 60 คำถามต่อนาทีต่อการเชื่อมต่อ รอสักครู่ |
| Claude บอกว่า token หมดอายุ / ต้องเชื่อมใหม่ | ไม่ได้ใช้เกิน 30 วัน หรือถูกยกเลิกที่หน้าแอปที่เชื่อมต่อ — กด Connect ใหม่ |
| ทุกอย่างตอบ "ใบอนุญาตใช้งานระบบหมดอายุ" | ติดต่อผู้ดูแลระบบ |
