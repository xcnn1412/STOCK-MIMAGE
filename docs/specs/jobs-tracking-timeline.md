# Spec: ไทม์ไลน์ — มุมมองที่ 2 ของหน้าติดตามงาน (/jobs/tracking?view=timeline)

Status: ready-for-agent · ต่อจาก `docs/specs/jobs-tracking-ui.md`
Glossary: `CONTEXT.md` (ไทม์ไลน์, เลน, แถบงาน, ความว่าง, ชน, ต่อคิว)

## Problem Statement

ตารางติดตามงานบอกได้ว่า "งานนี้ขาดอะไร" แต่ตอบไม่ได้ว่า "วันพุธนี้ใครว่างช่วงบ่าย / รถ Triton ว่างกี่โมง / งาน A กับ B แบ่งคนยังไง" — ฝ่ายประสานงานต้องเปิดหลายแถวแล้วคำนวณเวลาในหัว วันที่มี 3–4 งานซ้อนกันจึงวางแผนพลาดง่าย

## Solution

ปุ่มสลับ `ตาราง | ไทม์ไลน์` ในหน้าเดิม ไทม์ไลน์วาดทรัพยากรเป็นเลน (งาน → รถ → คนทุกคนแยกแผนก) เทียบกับเวลา — โหมดวัน (ชั่วโมง) และโหมดสัปดาห์ (7 วัน) งานเดียวกันเป็นสีเดียวกันทุกเลน งานที่ชนกันขอบแดง งานที่ยังไม่ใส่เวลาเป็นแถบลายทาง คลิกแถบเพื่อจัดคน/เลือกรถด้วยหน้าต่างเดิม

## User Stories

1. As ฝ่ายประสานงาน, I want ปุ่มสลับ "ตาราง | ไทม์ไลน์" ที่จำไว้ใน URL, so that ส่งลิงก์มุมมองไทม์ไลน์ให้เพื่อนร่วมทีมได้
2. As ฝ่ายประสานงาน, I want เปิดไทม์ไลน์มาที่วันนี้ มีปุ่ม ← วันก่อน / วันนี้ / วันถัด → และ "งานถัดไป", so that ไปถึงวันที่ต้องวางแผนได้ในคลิกเดียว
3. As ฝ่ายประสานงาน, I want โหมดวันมีแกนชั่วโมง 06:00–24:00 ที่ตำแหน่งคงที่ (ขยายเองถ้ามีงานเช้ากว่านั้น), so that เทียบวันต่อวันด้วยสายตาได้
4. As ฝ่ายประสานงาน, I want เลน "งาน" บนสุดแสดงทุกงานของวัน และงานที่ยังไม่มีคน/รถเลยเป็นขอบประ, so that งานที่ยังไม่ได้จัดอะไรเลยไม่หายไปจากแผน
5. As ฝ่ายประสานงาน, I want เลนรถ 2 คัน แล้วเลนคนทุกคนที่อนุมัติแล้ว แบ่งกลุ่มตามแผนก (รวมคนที่ยังไม่ตั้งแผนก), so that เห็นทั้งทีมว่าใครว่าง ไม่มีใครตกหล่น
6. As ฝ่ายประสานงาน, I want ปุ่ม "ซ่อนคนว่าง", so that วันที่ทีมใหญ่แต่มีงานน้อยดูกระชับ
7. As ฝ่ายประสานงาน, I want งานเดียวกันเป็นสีเดียวกันในทุกเลน ป้ายเป็นชื่อลูกค้า และในเลนคนมีตำแหน่งต่อท้าย, so that ไล่สายตาว่างานหนึ่งใช้ใคร/รถอะไร และใครทำตำแหน่งไหน
8. As ฝ่ายประสานงาน, I want งานที่ยังไม่ใส่เวลาเริ่มเป็นแถบลายทางเต็มวัน "ยังไม่ใส่เวลา" และงานที่ไม่มีเวลาสิ้นสุดยาว 2 ชม. ปลายลายทาง, so that รู้ว่าต้องไปกรอกเวลาใน CRM ก่อนวางแผนจริง
9. As ฝ่ายประสานงาน, I want งานที่ชนเวลากันในเลนเดียว วางซ้อนเป็นชั้นและขอบแดงทั้งคู่, so that เห็นจุดชนโดยไม่ต้องอ่านตัวเลข
10. As ฝ่ายประสานงาน, I want คลิกแถบในเลนคน/เลนงานเปิดหน้าต่างจัดคนของงานนั้น และคลิกแถบในเลนรถเปิดตัวเลือกรถ, so that แก้แผนได้ตรงจุดโดยไม่กลับไปตาราง
11. As ฝ่ายประสานงาน, I want โหมดสัปดาห์ (7 วันนับจากวันที่เลือก) แสดงบล็อกงานต่อวันในแต่ละเลน, so that เห็นว่าใครหนัก/ใครว่างทั้งสัปดาห์
12. As คนหน้างาน (มือถือ), I want โหมดวันเลื่อนแนวนอนได้ ชื่อเลนติดซ้าย, so that เช็คแผนวันนี้บนมือถือได้
13. As ผู้ใช้ทุกคน, I want การจัดคน/เลือกรถจากไทม์ไลน์อัปเดตแถบทันทีทั้งไทม์ไลน์และตาราง, so that ไม่ต้องรีโหลดเพื่อดูผล
14. As ผู้ดูแลระบบ, I want รายการนี้ใน "มีอะไรใหม่", so that ทีมรู้ว่ามีมุมมองใหม่

## Implementation Decisions

- **ไม่มี schema ใหม่ / ไม่เพิ่ม library** — วาดด้วย CSS grid; ข้อมูลเวลา = วันเริ่ม–สิ้นสุด, เวลาเริ่ม–สิ้นสุด ของงาน; คน = event_staff; รถ = key ใน tracking_checklist; รายชื่อคน = profiles ที่อนุมัติแล้วพร้อมแผนก
- **Seam เดียว** ขยายโมดูล logic บริสุทธิ์เดิม: `layoutDay(leads, date, people, roleLabels, opts)` และ `layoutWeek(...)` คืนโครงสร้างเลน/แถบที่ UI แค่ map เป็น div — ตำแหน่ง (นาทีจากเริ่มวัน), ความกว้าง, ชั้นซ้อน, สี, ธงชน, ธงยังไม่จัด คำนวณในนี้ทั้งหมด; `nextJobDate(leads, from)` สำหรับปุ่มงานถัดไป
- ลำดับเลน: งาน → รถ (ตาม VEHICLES) → คน เรียงกลุ่มแผนก (ช่าง, ฝ่ายประสานงาน, ฝ่ายออกแบบ, ฝ่ายแอดมิน, ผู้บริหาร, นักศึกษาฝึกงาน, ไม่ระบุแผนก) แล้วชื่อ; "ซ่อนคนว่าง" ตัดเลนคนที่ไม่มีแถบ
- แกนชั่วโมง: 06–24 คงที่ ถ้ามีงานเริ่มก่อน 06:00 ขยับจุดเริ่มลงเป็นชั่วโมงเต็มที่เล็กกว่า; งานหลายวันที่คร่อมวันที่ดู = แถบเต็มวัน
- สี: palette 10 สีคงที่ ให้ตามลำดับงานในช่วงที่ดู (วัน/สัปดาห์) — งานเดียวกันได้ index เดียวกันทุกเลน
- ชั้นซ้อน: จัดแบบ greedy ตามเวลาเริ่ม; ธงชนใช้ `timeStatus` เดิม (ทับเวลา = ชน, ชิดกัน = ไม่ชน, ไม่รู้เวลา = ไม่ติดธง)
- สัปดาห์ = 7 วันนับจากวันที่เลือก (rolling) — เซลล์ต่อวันมีบล็อกงานเรียงตามเวลา; ซ่อนบนจอแคบกว่า md
- สถานะมุมมองอยู่ใน URL: `?view=timeline&date=YYYY-MM-DD&mode=day|week` — เปิดโดยไม่มี date = วันนี้
- ไทม์ไลน์ไม่สนใจชิปกรอง/ปุ่มซ่อนงานที่ผ่านแล้วของตาราง (คนละมิติ: ตารางกรองตามความพร้อม ไทม์ไลน์เลือกตามวัน)
- คลิกแถบเปิด `StaffEditor` / dialog เลือกรถ ตัวเดิม; หลังบันทึก state แถวเดียวกันอัปเดต → ไทม์ไลน์คำนวณใหม่จาก rows เดียวกัน
- ไม่ลาก-วาง, ไม่แก้เวลาจากไทม์ไลน์, ไม่ดึงการลา

## Testing Decisions

- **TDD ที่ seam**: เขียน assert ใน check script ก่อน (แดง) แล้วค่อยเขียน `layoutDay`/`layoutWeek`/`nextJobDate` (เขียว) — รันด้วย `npx tsx` ไม่มี framework
- เคสที่ต้องมี: ช่วงชั่วโมง default/ขยาย, แถบ no_time/no_end/multi_day, สีเท่ากันข้ามเลน, ชั้นซ้อน 2–3 งาน, ธงชน vs ชิดกัน, เลนคนตามลำดับแผนก + ซ่อนคนว่าง, เลนงาน "ยังไม่จัด", สัปดาห์ 7 วันและบล็อกต่อวัน, nextJobDate ข้ามวันว่าง/ไม่มี
- UI ตรวจด้วยตาใน `npm run dev` ทั้งเดสก์ท็อปและความกว้างมือถือ + `npx tsc --noEmit` ไม่มี error ในไฟล์ที่แตะ; ปิดท้ายด้วย `/code-review`

## Out of Scope

- ลาก-วางคน/รถ หรือลากปลายแถบเปลี่ยนเวลา
- เวลาเดินทาง/ติดตั้ง/เก็บงานแยกจากเวลางาน
- การลา (leave_requests) ในเลนคน
- โหมดสัปดาห์บนมือถือ
- พิมพ์/ส่งออกไทม์ไลน์

## Further Notes

- ถ้าภายหลังต้องการ "ช่วงเวลาใช้รถ" ต่างจากเวลางาน ให้เพิ่มคอลัมน์ที่ lead แล้วส่งเข้า seam เป็น start/end ของแถบรถ — UI ไม่ต้องเปลี่ยน
