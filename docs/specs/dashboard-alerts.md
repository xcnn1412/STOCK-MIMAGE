# Spec: ระบบแจ้งเตือนงานบน Dashboard (dashboard-alerts)

> ที่มา: session วางแผน 2026-09-01 (grilled + confirmed) — ปัญหาคือ user ไม่สนใจกระดิ่ง notification
> จึงย้ายการแจ้งเตือนสำคัญของงานมา "ขวางตา" บนหน้าที่ทุกคนผ่านแน่นอน

## เป้าหมาย

1. user เห็นทันทีว่าตัวเองมีใบงานค้างในมือกี่ใบ (ถูก assign มาก็ไม่พลาด แม้ไม่เคยกดกระดิ่ง)
2. งานที่ใกล้วันงานแต่หน้าที่เตรียมงานยังไม่ครบ (ออกแบบ/จัดคน/จัดรถ/เวลา/กระเป๋า)
   ถูกดันขึ้นมาเตือนคนที่แก้ได้จริง ก่อนถึงหน้างานแล้วค่อยรู้ว่าไม่พร้อม

## หลักการที่ล็อกแล้ว (จากการ grill)

- **คำนวณสดตอนเปิดหน้า** — ไม่มี cron, ไม่มีตารางใหม่, ไม่มี notification type ใหม่
- **ปิด/ซ่อนไม่ได้** — คำเตือนหายเองเมื่อของครบหรือใบงานจบ/ถูก archive เท่านั้น
- แผงว่าง = ไม่ render อะไรเลย (หน้า dashboard กลับมาโล่งเหมือนเดิม)

## แผงที่ 1 — "งานในมือคุณ"

- นับใบงานพูล (`jobs`) ที่ user เป็น `claimed_by` หรืออยู่ใน `assigned_to`
  และสถานะยังไม่จบ (ไม่ใช่ done/skipped)
- แสดงรายใบสูงสุด 5 แถว เรียงวันงานใกล้สุดก่อน: ชื่องาน · ประเภท (กราฟิก/หน้างาน) · วันงาน · สถานะ
- เกิน 5 ใบ → ลิงก์ "ดูทั้งหมด" ไป `/jobs/tracking`
- กดแถว → แท็บพูลของประเภทนั้นพร้อมไฮไลต์งาน (กลไก `?tab=...&lead=<id>` ที่มีอยู่)

## แผงที่ 2 — "หน้าที่ยังไม่ครบ ใกล้วันงาน"

- ขอบเขตงาน: `crm_leads` ที่มี `event_date` ในช่วง **[วันนี้−14 วัน, วันนี้+7 วัน]**,
  ไม่ archive, งานไม่ระบุวันไม่เข้าแผง
- เกณฑ์ "ไม่ครบ" = `getMissing()` จาก `tracking-logic.ts` (สัญญาณเดียวกับป้าย "สิ่งที่ยังขาด" ในพูล)
  — ห้ามเขียนเกณฑ์ซ้ำใหม่
- ระดับความแรง (นับวันปฏิทินตรงๆ):
  - เหลือ 4–7 วัน → เหลือง
  - เหลือ ≤3 วัน → แดง
  - เลยวันงานแล้ว → แดงเข้ม + ตัวหนา "เลยวันงานแล้ว"
- ผู้เห็นคำเตือนของแต่ละงาน (union):
  - หน้าที่ที่มีคนรับแล้ว (`lead_duty_claims` / ใบงานกราฟิกมีผู้รับ) แต่ยังไม่ครบ → เตือน**เจ้าของหน้าที่นั้น**
  - หน้าที่ยังไม่มีคนรับ → เตือน**ทุกคนในแผนกที่รับผิดชอบหน้าที่นั้น**
    (แผนกอ่านจาก `job_settings` เดิม: `pool_duty_*` + แผนกทีมกราฟิก/หน้างาน)
  - **แอดมิน + ฝ่ายประสานงาน** เห็นทุกงานเสมอ
- กดคำเตือน → แท็บของหน้าที่ที่ขาดใน `/jobs/tracking` พร้อมไฮไลต์งานนั้น
  (ต้องขยายไฮไลต์ `?lead=` ให้ครอบแท็บจัดคน/จัดรถ/จัดกระเป๋าด้วย — ตอนนี้มีเฉพาะกราฟิก/หน้างาน)

## ตำแหน่งแสดงผล

- `/dashboard` — บนสุด เหนือ tile โมดูล (หน้าเปลี่ยนจาก static เป็นมีชั้นข้อมูล server)
- `/jobs/tracking` — แถบเดียวกันเหนือแท็บพูล
- ใช้ component ชุดเดียวกันทั้งสองหน้า

## นอกขอบเขต (ตัดสินแล้วว่าไม่ทำ)

- cron / แจ้งเตือน ณ จุดเวลา 7 วัน/3 วันเป๊ะๆ (ใช้แผงค้างสดแทน)
- งานไม่ระบุวันในแผงเตือน
- ปุ่มรับทราบ/ซ่อนคำเตือน
- แจ้งเหตุการณ์ "กดรับงานเอง" (รู้อยู่แล้ว — กระดิ่ง `job_assigned` ตอนถูก assign มีอยู่เดิม)
