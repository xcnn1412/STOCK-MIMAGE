# Spec: หน้าสถิติทีม /reports (team-reports)

> ที่มา: session วางแผน 2026-09-01 — อยากเห็นตัวเลขการออกงาน/รับงานของทีมจากหน้า dashboard

## เป้าหมาย

ทุกคนเห็นภาระงานจริงของทั้งทีมในที่เดียว: ใครออกงานอีเวนต์กี่ครั้ง ใครรับหน้าที่
จัดคน/จัดรถ/จัดกระเป๋า และใครรับใบงานกราฟิก — แยกดูตามช่วงเวลาได้

## หลักการที่ล็อกแล้ว

- **หน้าใหม่ `/reports`** — ทุกคนที่ล็อกอินเข้าได้ อยู่นอก `MODULE_ROUTES` แบบเดียวกับ
  `/whats-new` (ตั้งใจ ไม่เพิ่ม module key) มีลิงก์เข้าจากหน้า dashboard
- **ตารางรวมทั้งทีม** แถวละคน ทุกคนเห็นเหมือนกัน แถวของตัวเองไฮไลต์
- ชิปช่วงเวลา: **ภาพรวม (ทั้งหมด) · สัปดาห์นี้ · เดือนนี้ · ปีนี้** — สลับฝั่ง client ไม่โหลดใหม่
- ไม่มี migration, ไม่มีตารางใหม่ — อ่านจากข้อมูลที่มีอยู่เท่านั้น

## นิยามการนับ (lock — ห้ามเปลี่ยนโดยไม่กลับมาแก้ spec)

| สถิติ | นับจาก | วันที่อ้างอิงสำหรับกรองช่วง |
|---|---|---|
| ออกงานอีเวนต์ | `event_staff` (ถูกจัดชื่อเข้าอีเวนต์) — นับ distinct อีเวนต์ต่อคน | `events.event_date` — นับเฉพาะงานที่**ถึงวันแล้ว** (event_date ≤ วันนี้) |
| จัดคน / จัดรถ / จัดกระเป๋า | `lead_duty_claims` รายหน้าที่ (`claimed_by`, `duty`) | วันที่กดรับหน้าที่ (`claimed_at`/`created_at` ของแถว claim) |
| รับงานกราฟิก | `jobs` ที่ `job_type='graphic'` และมี `claimed_by` | `claimed_at` ของใบงาน |
| ยอดนักขาย | คนสร้าง CRM card (`crm_leads.created_by`) ที่งานถึงสถานะ `accepted` — หนึ่ง lead นับให้ผู้สร้างหนึ่งครั้ง | `created_at` ของ lead (วันตอบรับไม่มีเก็บแยก) |
| สร้างใบงาน | แถวใน `jobs` ตาม `created_by` (ทุกประเภทใบงาน) | `created_at` ของใบงาน |

ข้อจำกัดที่ยอมรับ: หน้าที่ที่รับแล้ว**คืน** แถว claim หายจากระบบ = ไม่นับ
(นับเฉพาะงานที่รับแล้วถือจริง — ไม่เก็บ log ประวัติเพิ่ม)

## หน้าตา

- การ์ดสรุปบนหัว: ยอดรวมทีมต่อประเภทในช่วงที่เลือก (5 ตัวเลข)
- ตาราง: ชื่อ (nickname | ชื่อเต็ม + แผนก) · ออกงาน · จัดคน · จัดรถ · จัดกระเป๋า · กราฟิก · รวม
- เรียงยอดรวมมากสุดก่อน · คนที่ทุกช่องเป็น 0 ในช่วงนั้นไม่ต้องแสดง
- มือถือ: ตารางเลื่อนแนวนอนใน overflow container

## เทคนิค

- server component ดึง raw 3 ชุด (event_staff+วันงาน, duty claims, graphic jobs+claimed_at)
  ส่งเป็นแถวเบาๆ (userId, ประเภท, วันที่) → client aggregate ตามแท็บเอง
- ตรรกะนับเป็นไฟล์ pure + ไฟล์ `*.check.ts` ตาม pattern ของ repo
- สัปดาห์เริ่มวันจันทร์ · เดือน/ปีตามปฏิทิน ค.ศ. ในข้อมูล แสดงผลแบบไทย
