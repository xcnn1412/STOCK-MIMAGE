## 1. เป้าหมาย

การ์ดที่ **อ่านได้ในแวบเดียว** (สรุปตอนพับ · ตัวเลขสำคัญอยู่บน · ไม่มีแถวว่าง) · **แก้ได้โดยไม่พลาด** (แก้ทีละใบ · ปุ่มบันทึกถึงมือ · ยืนยันก่อนทิ้ง draft) · **ดูเป็นชุดเดียวกับทั้งแอป** (วันที่ไทย พ.ศ. · ไอคอน lucide · ตัวอักษร ≥ 12px · เป้านิ้ว ≥ 40px) · ใช้ได้เท่ากันบน 390px และ 1280px

## 2. สิ่งที่จะทำ (ตามลำดับความคุ้ม)

### เฟส A — โหมดดู (ไม่เปลี่ยนพฤติกรรม)
1. **วันที่ไทย**: ค่าวันที่ทุกแถว (วันจัดงาน วันสิ้นสุด วันนัดชำระ วันที่ชำระจริง) ผ่าน `lib/thai-date.ts::formatThaiDate` → "20 ธันวาคม 2642" · เวลา "10:00 น." คงเดิม (ตอบ P1)
2. **ซ่อนแถวว่าง** ในโหมดดู ยกเว้นช่องหลัก 4 ช่อง (ชื่อ, โทรศัพท์, วันจัดงาน, ราคา) ที่แสดง "ไม่ระบุ" จางๆ — `InfoRow` รับ `hideEmpty` ค่าเริ่มต้น true (ตอบ P2) · โหมดแก้ไขยังเห็นทุกช่อง
3. **InfoRow ซ้อนแนวตั้งบนจอแคบ**: `flex-col gap-0.5 sm:flex-row` ป้ายบน ค่าล่างชิดซ้าย; ≥ sm กลับเป็นป้ายซ้าย ค่าขวาเหมือนเดิม · ค่าหลายบรรทัด (รายละเอียด หมายเหตุ) ชิดซ้ายเสมอ (ตอบ P13)
4. **อีโมจิ → lucide** (`Calculator`, `Receipt`, `CheckCircle2`, `AlertTriangle`, `Wallet`, `Check`) ขนาด `h-3.5 w-3.5` (ตอบ P6)
5. **ขั้นต่ำ 12px**: `text-[10px]`/`text-[9px]` → `text-xs`; badge CRM ที่หน้าใบงาน `text-[8px]` → `text-[10px]` (ตอบ P7)
6. **เป้านิ้ว**: ปุ่มดินสอ/ลูกศรหัวการ์ด `h-9 w-9` (36px) + `-mr-2` ให้ไอคอนอยู่ที่เดิม; ปุ่ม เปลี่ยน/ลบ สลิป `h-8` (ตอบ P8)
7. **สลิป**: โหมดดู = ดูรูป + อัปโหลด/เปลี่ยน ได้ (ทางลัดของพนักงาน) แต่ **ไม่มีปุ่มลบ** · ภาพสลิปเป็นลิงก์เปิดขนาดเต็มเสมอ (ไม่พึ่ง hover) ทั้ง 2 โหมด (ตอบ P4 · ดู Q1)
8. **ยอดค้างชำระ**: แสดงเมื่อมี `confirmed_price` หรือมัดจำ/งวดที่ชำระแล้ว; ถ้ามีแค่ราคาเสนอ แสดงบรรทัดจางๆ "ยังไม่ตกลงราคา (เสนอ ฿15,000)" แทนกล่องเหลือง (ตอบ P12 · เป็นเงื่อนไขแสดงผล ไม่แตะสูตร)

### เฟส B — การ์ดอ่านได้ในแวบเดียว
9. **สรุปตอนพับ** ในหัวการ์ด (บรรทัดที่สอง `text-xs text-zinc-500 truncate` แสดงเฉพาะตอน `collapsed`): ลูกค้า = ชื่อ · โทร · ช่องทาง | อีเวนต์ = วันที่ไทย · สถานที่ | การเงิน = "ค้าง ฿16,200" (ส้ม) / "ชำระครบ" (เขียว) / "ยังไม่ตกลงราคา" (ตอบ P3) · `CollapsibleCardHeader` รับ `summary?: ReactNode`
10. **แถบตัวเลขการเงินด้านบน** ของการ์ดการเงินโหมดดู: 3 ช่อง ยอดสุทธิ / ชำระแล้ว / ค้างชำระ (`grid-cols-3`, ตัวเลข `text-base font-semibold tabular-nums`) แล้วรายละเอียด (ราคาเสนอ/ยืนยัน/มัดจำ/ภาษี/งวด) อยู่ใต้ — ใช้ค่าจาก `calcTax`/`balance` ที่มีอยู่ ไม่คิดใหม่

### เฟส C — แก้ไขโดยไม่พลาด
11. **Select เต็มแถว**: `EditSelect` ใส่ `className="w-full"` ที่ `SelectTrigger` (ตอบ P5)
12. **จับคู่ช่องบน ≥ sm**: วันจัดงาน|วันสิ้นสุด, เวลาเริ่ม|เวลาสิ้นสุด, ราคาเสนอ|ราคายืนยัน, LINE|โทรศัพท์ เป็น `grid sm:grid-cols-2 gap-3` (จอแคบยังเรียงเดี่ยว) ลดความสูงฟอร์มราว 30% (ตอบ P9)
13. **ปุ่มบันทึก/ยกเลิกที่หัวการ์ดด้วย** ตอนแก้ไข (แทนดินสอ+ลูกศร) คงปุ่มล่างไว้; บนจอแคบปุ่มล่างเป็นแถบ `sticky bottom-0` พื้นขาวในการ์ด (ตอบ P9 · ดู Q4)
14. **แก้ทีละใบ**: ขณะใบหนึ่งแก้อยู่ ดินสอของอีกสองใบไม่แสดง (`EditableCardProps.editLocked`) (ตอบ P10)
15. **ยืนยันก่อนทิ้ง draft**: กด "ยกเลิก" ขณะฟอร์มต่างจากค่าเดิม → `askConfirm` "ทิ้งการแก้ไข?" (ใช้ `useConfirm` ที่รับมาแล้ว) · ฟอร์มไม่ต่าง = ยกเลิกทันที
16. **toast สำเร็จ** "บันทึกแล้ว" หลังบันทึก (ตอบ P11) · **Esc** = ยกเลิก (ผ่านข้อ 15), **Ctrl/⌘+Enter** = บันทึก ในขณะโฟกัสอยู่ในการ์ดที่แก้ (ตอบ P14)
17. **ช่องเงิน**: `inputMode="decimal"` + คำนำหน้า "฿" ในช่อง (`relative` + `pl-7`) + `min={0}` · ช่องโทรศัพท์ `type="tel"` · LINE `autoCapitalize="none"`

### เฟส D — นอกการ์ด (ตัดสินใจก่อน ไม่อยู่ใน v1.54.0)
- หน้า `/crm/[id]`: การ์ดลูกค้า/อีเวนต์/การเงินอยู่ล่างสุดใต้ สรุปต้นทุน → อีเวนต์ที่ผูก → สถานะ → แท็ก → ทีมงาน (จอใหญ่เริ่มที่ 1,700px จาก 3,400 · มือถือต้องเลื่อนราว 2,000px) ข้อเสนอ: ย้าย 3 การ์ด + ไทม์ไลน์ขึ้นถัดจากแถบสถานะ ส่วนสรุปต้นทุน/อีเวนต์ที่ผูก/แท็ก/ทีมงานลงล่าง หรือทำสรุปต้นทุนเป็นการ์ดพับได้ (Q5)
- การ์ดทีมงาน: ผู้ใช้ที่ไม่พบ profile แสดง UUID ดิบ + "unknown_role" → "ไม่พบผู้ใช้" / "ไม่ระบุหน้าที่"
