# ค่าสตาฟคิดในโมดูลเงินเดือนเท่านั้น — เลิกสร้างใบเบิกค่าสตาฟอัตโนมัติจากเช็คอิน

เดิม check-out "ไปหน้างาน" สร้างใบเบิก "ค่าสตาฟ" ในโมดูลการเงินอัตโนมัติ (`autoCreateExpenseFromCheckin`) โดยคิดจาก **บทบาทในอีเวนต์** (`event_staff.role` × `crm_settings.staff_role.price`) เมื่อเพิ่มโมดูลเงินเดือนที่คิดค่าสตาฟจาก **หน้าที่หน้างาน** ที่ติ๊กตอนเช็คอิน จะมีสองระบบจ่ายเงินก้อนเดียวกัน เราตัดสินใจให้สลิปเงินเดือนเป็นที่เดียวที่คิดค่าสตาฟ ลบ `autoCreateExpenseFromCheckin` และตั้ง `auto_calc_enabled = false` ใบเบิกในโมดูลการเงินเหลือไว้สำหรับค่าใช้จ่ายสำรองจ่ายจริงเท่านั้น

## Considered Options

- **เก็บทั้งสองไว้ ให้ admin ระวังเอง** — ปฏิเสธ: จ่ายซ้ำเป็นความผิดพลาดที่เกิดเงียบๆ และตรวจย้อนหลังยาก
- **ให้สลิปดึงยอดจากใบเบิกที่อนุมัติแล้ว** — ปฏิเสธ: ใบเบิกคิดจากบทบาทวางแผน ไม่ใช่หน้าที่ที่ทำจริง และหนึ่งเช็คอินได้หลายหน้าที่/เบิ้ลต่างจังหวัด/รันเนอร์ ซึ่งโครงใบเบิกไม่รองรับ
- **ใส่หน้าที่ใหม่ลง `staff_role` แล้วใช้ราคาตรงนั้น** — ปฏิเสธ: `staff_role` คือบทบาทที่ถูกมอบหมายตอนวางแผน (ฝ่ายขาย/กราฟิก) ใช้ในหน้าอีเวนต์/CRM ด้วย ปนกันแล้วหน้าที่หน้างานจะโผล่ในหน้ามอบหมายงาน (ดู `CONTEXT.md`: บทบาทในอีเวนต์ ≠ หน้าที่หน้างาน)

## Consequences

- `expense_claims.from_checkin_id` และ `backfillCheckinEvents` คงไว้เพื่ออ่านข้อมูลเก่า แต่ไม่มีแถวใหม่ที่ `from_checkin_id` ไม่ว่างอีก
- `crm_settings.staff_role.price` / `auto_calc` ไม่มีผู้ใช้ในโค้ดอีก — UI ตั้งค่าใน `/finance/settings` ถูกซ่อน (ยังไม่ลบคอลัมน์)
- ใบเบิกค่าสตาฟที่ค้างก่อนวันเปิดใช้ต้องปิดให้จบตาม flow เดิมด้วยมือ
