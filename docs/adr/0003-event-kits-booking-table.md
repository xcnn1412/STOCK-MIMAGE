# จองกระเป๋าผ่านตาราง event_kits แทน kits.event_id เดี่ยว

`kits.event_id` ผูกกระเป๋าได้ทีละหนึ่งอีเวนต์ ทำให้วางแผนล่วงหน้าไม่ได้ (จองกระเป๋าให้งานสัปดาห์หน้าไม่ได้ถ้าวันนี้ยังอยู่กับอีกงาน) และเลนกระเป๋าบนไทม์ไลน์จะเห็นได้ทีละงานเดียว เราจึงเพิ่มตารางจอง `event_kits` (event_id, kit_id, packed_at, packed_by) — กระเป๋าใบเดียวจองหลายอีเวนต์คนละวันได้, กติกาชน = จองสองอีเวนต์วันเดียวกัน (เข้มกว่าคน/รถ: ไม่ดูเวลา ไม่มีต่อคิว), สถานะจัดกระเป๋าเก็บต่อการจองจึงรีเซ็ตเองเมื่อย้ายอีเวนต์ `kits.event_id` เดิมคงไว้เพื่อ backward compat กับ flow เช็ค/คืนกระเป๋าเดิม โดยถือว่า event_kits เป็น source of truth ของการจอง
