# 01: Prefactor — แยกชั้นข้อมูล tracking เป็นฟังก์ชันกลาง

**What to build:** หน้าติดตามงาน (/jobs/tracking) ทำงานเหมือนเดิมทุกประการ แต่การประกอบข้อมูลทั้งหมด (งาน อีเวนต์ ทีม ใบงาน duty claims กระเป๋า รถ settings) ย้ายออกจากตัวหน้าไปเป็นฟังก์ชัน server กลางที่หน้าอื่นเรียกใช้ซ้ำได้ — เพื่อให้แผงแจ้งเตือนบน dashboard ใช้ข้อมูลชุดเดียวกันโดยไม่ก๊อปคิวรี

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] /jobs/tracking แสดงผลและทำงานเหมือนก่อนแก้ทุกแท็บ (ภาพรวม/กราฟิก/จัดคน/จัดรถ/จัดกระเป๋า/หน้างาน)
- [ ] มีฟังก์ชันกลางฟังก์ชันเดียวที่คืนข้อมูลครบพอให้คำนวณความพร้อมของงาน (getMissing/kitReadiness/designReady) ได้จากภายนอกหน้า tracking
- [ ] `npx tsc --noEmit` ไม่มี error ใหม่
