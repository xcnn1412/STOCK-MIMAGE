# 01: บอร์ดวันงาน — kanban หน้างานอย่างเดียว 7 วัน + แถบใบงานลอย + เปลี่ยนชื่อเมนู

**What to build:** /jobs เปิดมาเป็น "บอร์ดวันงาน": kanban เฉพาะใบงานหน้างาน (ตัดบอร์ดกราฟิกทิ้ง) ช่วงเริ่มต้น 7 วันข้างหน้า พร้อมชิปกรอง "วันนี้" / "ทั้งหมด" · ใต้บอร์ดมีแถบ "ใบงานลอย" (ใบงานที่ไม่ผูก CRM ทุกประเภท) พร้อมปุ่มสร้างงานเดิม · เมนู sidebar เปลี่ยนชื่อเป็น "บอร์ดวันงาน" — /jobs/[id], /jobs/settings, /jobs/tracking เดิมไม่กระทบ

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] /jobs แสดง kanban เฉพาะ job_type onsite — ไม่มีบอร์ด/แท็บกราฟิกเหลืออยู่
- [ ] ค่าเริ่มต้นเห็นงานช่วงวันนี้ถึง +7 วัน · ชิป "วันนี้" เหลือเฉพาะวันนี้ · "ทั้งหมด" เห็นครบ
- [ ] แถบใบงานลอย (crm_lead_id null) แยกใต้บอร์ด แสดงครบและสร้างงานใหม่ได้เหมือนเดิม
- [ ] เมนู sidebar ขึ้น "บอร์ดวันงาน" (สิทธิ์ module jobs เดิม)
- [ ] logic กรองช่วงวัน + แยกใบงานลอย เป็นฟังก์ชัน pure + assert ใน check file ผ่าน
- [ ] `npx tsc --noEmit` ไม่มี error ใหม่ และ `npm run build` ผ่าน
