# 02: ป้าย "ยังไม่เปิดใบงาน" ในคอลัมน์ออกแบบ

**What to build:** คอลัมน์ออกแบบในตารางภาพรวม (และการ์ดมือถือ) ไล่สถานะเป็นขั้น: งานที่ไม่มีใบงานกราฟิก = ป้าย "ยังไม่เปิดใบงาน" โทนเตือน (แทน dropdown เดิม — งานเก่าก่อนยุคพูลก็เข้าเกณฑ์นี้) → มีใบงานรอรับ = ปุ่มรับงาน (เดิม) → รับแล้ว = dropdown สถานะออกแบบ (เดิม) ฝ่ายประสานงานเห็นทันทีว่างานไหนถูกลืมเปิด พร้อมอัปเดตหน้า "มีอะไรใหม่"

**Blocked by:** 01

**Status:** done (2026-08-31) — เกณฑ์ผ่านครบ (tsc/check/build), review แล้ว

- [ ] logic ตัดสินสถานะช่องออกแบบ (ยังไม่เปิด/รอรับ/แก้ได้) เป็นฟังก์ชัน pure ใน tracking-logic + assert ครบทุกกิ่งใน check file และ check ผ่าน
