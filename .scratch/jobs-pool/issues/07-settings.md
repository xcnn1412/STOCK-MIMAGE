# 07: ตั้งค่าทีมและสิทธิ์กระเป๋าใน /jobs/settings

**What to build:** หน้า /jobs/settings (admin) เพิ่มส่วนตั้งค่า: แผนกไหนเห็น/รับใบงานประเภทไหน และแผนกไหนจอง/ย้ายกระเป๋าได้ — เลือกจากรายการแผนกที่มี ค่าเริ่มต้นตาม spec (กราฟิก=ฝ่ายออกแบบ, หน้างาน=ทีมออกหน้างาน+สตาฟ+ช่าง, กระเป๋า=ทีมหน้างานชุดเดียวกัน) การแจ้งเตือนใบงานใหม่ สิทธิ์กดรับ และสิทธิ์จองกระเป๋าทั้งหมดอ่านจากค่านี้ เก็บใน job_settings ไม่แตะ schema

**Blocked by:** 01 (จุดอ่าน settings ตอนแจ้งเตือน), 03 (enforce ตอนรับงาน), 05 (enforce ตอนจองกระเป๋า)

**Status:** ready-for-agent

- [ ] admin แก้ mapping แผนก↔ประเภทใบงาน และแผนกจองกระเป๋า ใน /jobs/settings ได้ ค่าคงอยู่หลัง reload
- [ ] เปลี่ยน mapping แล้วการแจ้งเตือนใบงานใหม่ไปหาแผนกชุดใหม่ และคนนอกแผนกกดรับ/จองกระเป๋าได้ `{ error }` ภาษาไทย
- [ ] ไม่ตั้งค่าเลย = default ทำงานเหมือนก่อนมีหน้า setting
- [ ] logic ตัดสินสิทธิ์ตามแผนกเป็นฟังก์ชัน pure + assert ใน check file และ check ผ่าน
- [ ] `npx tsc --noEmit` ผ่าน
