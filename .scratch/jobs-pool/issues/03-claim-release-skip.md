# 03: รับงาน / คืนงาน / ข้ามใบงาน / เปลี่ยนคนรับ

**What to build:** สมาชิกฝ่ายกด "รับงาน" บนใบงานในพูล — กราฟิก: ผู้รับเป็นเจ้าของงานออกแบบ, หน้างาน: ผู้รับเป็นหัวหน้างานผู้รับผิดชอบ คนที่สองกดพร้อมกันต้องไม่ทับกัน (รับได้เฉพาะสถานะรอรับงาน) ผู้รับ "คืนงาน" กลับเข้าพูลได้ (แจ้งเตือนทีมอีกครั้ง) แอดมิน+ฝ่ายประสานงาน "เปลี่ยนคนรับ" และ "ข้ามใบงาน" ได้ (ข้าม = ออกจากพูล ไม่มีผู้รับ พร้อมเหตุผล) ทุกการกระทำแจ้งเตือนแอดมิน+ฝ่ายประสานงาน และลง activity log

**Blocked by:** 02 (ต้องมีแท็บพูลให้วางปุ่ม)

**Status:** ready-for-agent

- [ ] กดรับงานแล้วใบงานแสดงชื่อผู้รับ สถานะขยับออกจากรอรับงาน — เรียก action ซ้ำจากอีก user ได้ error ไม่ทับ
- [ ] คืนงานได้เฉพาะผู้รับเอง — ใบงานกลับเป็นรอรับงาน + notifications ถึงทีมฝ่ายนั้น
- [ ] ข้าม/เปลี่ยนคนรับ ทำได้เฉพาะ admin role หรือคนแผนกฝ่ายประสานงาน — user อื่นได้ `{ error }` ภาษาไทย
- [ ] ใบงานที่ถูกข้ามหายจากแท็บฝ่าย แต่งานยังอยู่ในแท็บภาพรวม
- [ ] แจ้งเตือน + logActivity ครบทุก action (ActionType ใหม่)
- [ ] `npx tsc --noEmit` ผ่าน
