# 01: สร้างใบงานอัตโนมัติเมื่อการ์ด CRM ตอบรับ + สถานะ "รอรับงาน" + แจ้งเตือนทีม

**What to build:** เมื่อการ์ด CRM เปลี่ยนสถานะเป็น "ตอบรับ" ระบบสร้างใบงานกราฟิกและใบงานหน้างานให้เองทันที (ถ้ายังไม่มีของงานนั้น — สลับสถานะไปมาไม่สร้างซ้ำ) ใบงานเกิดมาพร้อมสถานะแรก "รอรับงาน" และสมาชิกแผนกของฝ่ายนั้น (ค่าเริ่มต้น: กราฟิก=ฝ่ายออกแบบ, หน้างาน=ทีมออกหน้างาน+สตาฟ+ช่าง — อ่านจากการตั้งค่า มี default ในโค้ด) ได้รับแจ้งเตือนกระดิ่ง "ใบงานใหม่เข้าพูล" การกระทำถูกบันทึกใน activity log

**Blocked by:** None (can start immediately)
